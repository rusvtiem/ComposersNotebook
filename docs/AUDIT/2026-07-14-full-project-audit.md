### A2. «Нет звука» (баг №8) — найден вероятный корень, ранее не начинали
`MIDIEngine.swift:25-28` и `rebuildAudioGraph():154-158`: порядок `wireAudioGraph()` → `startEngine()` → `setupAudioSession()`. Движок стартует под дефолтной сессией ДО активации `.playback`. На устройстве в silent-mode = тишина. Второй пласт: `setInstrument` шлёт programChange в бедный бандл-SF2 (пустой пресет → нота молчит, M1); `loadSoundFont` при битом файле НЕ грузит fallback, молча `isSoundFontLoaded=false` (M2); CC70 отправляется как «sustain», хотя это Sound Variation — на части банков глушит (H4).
**Действие:** переставить `setupAudioSession()` перед `startEngine()`, проверить program/fallback. Проверяемо headless-логом выхода сэмплера частично; финально — на устройстве.

### A3. Экспорт нот ломает баланс времени в такте → сдвиг геометрии → промах тапа
Прямой мост к багам тапа/выделения. Три источника, все в `MusicXMLExporter.swift`:
- **H1** (`:423-431`): полнотактовая пауза всегда `<type>whole>` + duration=1920 даже в 3/4 (должно 1440), без `measure="yes"`. Verovio неверно центрует и ругается на баланс.
- **H2** (`:316,281-282`): cross-staff `<backup>` меряется по длине ПОСЛЕДНЕГО голоса, а не полного стана. Двухголосная левая рука grand staff съезжает по времени.
- **M4** (`:683,750`): tuplet duration округляется (`Int((actualBeats*480).rounded())`), квинтоль/септоль накапливают ошибку, сумма голоса ≠ целому такту.
Любой из трёх рвёт сумму `<duration>` → Verovio сдвигает геометрию → тап резолвится в соседнюю ноту.

### A4. Скрытые мины рядом с page-margin фиксом
- **CRITICAL-1** (`VerovioSVGGeometry.swift:73-91` + surface `:158,246`): `viewBox.origin` (minX/minY) читается, но НЕ вычитается из координат тапа — прибавляется только pageMarginOffset. Verovio сейчас даёт `viewBox="0 0..."`, поэтому молчит, но любой ненулевой origin сдвинет всю интерактивность. Комментарий врёт, что origin учтён.
- **CRITICAL-2** (`VerovioStaffSurface.swift:76-85,144`): `unitToPoint` считается только от ширины; флор высоты `max(...,120)` рвёт X/Y-пропорцию в вырожденных размерах → вертикальный рассинхрон тапа/каретки.

## БЛОК B — ВАЖНО (работает частично / вернётся)

### B1. Multi-page обрезается молча
`VerovioEngine renderToSVG(1, ...)` — всегда только страница 1. Длинная партитура (>1 листа A4) обрезается без индикатора. (агент1 HIGH-1)

### B2. Импорт MusicXML разваливает многоголосие и grand staff
`MusicXMLImporter.swift` не читает `<backup>`/`<forward>`/`<staff>` (C2) и `<duration>`/`divisions` (C3). Round-trip (свой экспорт → правка → импорт, или чужой MuseScore-файл фортепиано) → всё в один стан, overflow, ноты без `<type>` становятся четвертями.

### B3. Хрупкий парсинг SVG (молча гасит весь ввод)
- **HIGH-3** (`VerovioSVGGeometry.swift:125-129`): `firstPixelSize` завязан на порядок атрибутов `<svg>`; при апгрейде Verovio регексом вернёт nil → parse=nil → вся геометрия пропадёт, тапы отключатся молча. При этом само поле дальше не используется.
- **MEDIUM-4** (`:143,168`): окно поиска notehead/rest ограничено 400 символами — нота с артикуляциями уедет за окно, пропадёт.
- **MEDIUM-2** (`:312-317`): `rank % staffCount` ломается, если Verovio скроет пустой стан (многоинструментные партитуры) → тап читает чужой клеф.

### B4. Grand-staff краш по индексу при экспорте
`MusicXMLExporter.swift:74,106,147,279`: цикл индексирует все станы по count первого стана; при рассинхроне длины станов (`Staff.removeMeasure` молча не удаляет при count<=1) — out-of-bounds краш. Нет guard.

### B5. Аудит 05.07 (~22 дефекта) — закрытие НЕ отслежено
Переключились на гравировку→миграцию, статус закрытия потерян. Среди них потенциально живые и опасные:
- **Автосейв фиктивный** (пишется, при старте не читается) → потеря работы пользователя.
- **Grand-staff краш** (фортепиано/орган → вылет).
- **Транспозиция объявлена, но не применяется нигде** (кларнет/труба звучат/пишутся не в той высоте).
- `wholeRest()` всегда 4 доли → ложный overflow в не-4/4.
- `NoteEvent.Equatable` тянет id → ломает undo/diff.
- Двойной учёт `Duration.beats` + `actualBeats` (триоли).
**Нужно:** проверить каждый по текущему коду — закрыт или жив.
