> Оговорка платформы: MuseScore — десктоп с клавиатурой (шорткаты 1–9, A–G, N, Ctrl+…). У нас iPad-тач: те же действия должны жить в **кнопках тулбара и жестах**, а не в клавишах. Поэтому сверяю не «есть ли клавиша», а **есть ли способ сделать это действие на экране и ведёт ли оно себя как в MuseScore**.

## §1. Режим ввода нот (Note input mode)

| MuseScore | Наш экран | Статус |
|---|---|---|
| N — вкл/выкл режим ввода, карандаш на тулбаре | Кнопки режимов: Навиг. / Нота / Пауза / Ре-питч (`NoteToolbarView.modeButtons`) | ✅ |
| Курсор ввода — вертикальная «тень» в позиции | Синяя каретка в `VerovioStaffSurface` | ⚠️ каретка есть; превью будущей ноты (как у MuseScore) нет |
| Метод по умолчанию — step-time: длительность → высота | Так и сделано: выбрал длительность (липнет) → ставишь ноту | ✅ |
| Клик по линейке ставит ноту | Тап по стану ставит ноту по высоте | 🐞 хит-тест ноты по глифу есть, но по паузе — нет (баг 2) |
| Клик по существующей ноте = добавить в аккорд; Shift+Click = заменить | Наоборот: добавление в аккорд только в явном режиме «Аккорд», иначе тап рядом = новая нота | ⚠️ осознанное отклонение (без случайных аккордов на тач), поведение задокументировано в коде |

## §2. Длительности

| MuseScore | Наш экран | Статус |
|---|---|---|
| Полный диапазон longa…1024th | Кнопки longa, breve, whole…64th (`DurationValue.allCases`) | ⚠️ до 64th (нет 128th…1024th — редко нужны) |
| Клавиши 1–9 взводят длительность до ноты | Кнопки длительностей на тулбаре | ✅ (адаптация под тач) |
| Точка `.` (до 4 точек, maxDots=4) | Кнопки • и •• (одинарная/двойная) | ⚠️ есть 1 и 2 точки, тройной/четверной нет |
| Q/W — уполовинить/удвоить; Shift+Q/W с точками | — | ❌ нет быстрой смены длительности выделенного «на лету» (только выбрать конкретную) |
| Sticky duration (липнет для следующих нот) | `selectedDuration` сохраняется | ✅ |

## §3. Ввод высоты

| MuseScore | Наш экран | Статус |

## §5. Паузы

| MuseScore | Наш экран | Статус |
|---|---|---|
| 0 — пауза текущей длительности | Режим «Пауза» → тап ставит паузу | ✅ ввод есть |
| Del — нота → пауза той же длительности (не удаляет) | `deleteSelectedEvent` заменяет на паузу той же длительности | ✅ верно |
| Такт всегда полон паузами (инвариант) | Не держится: ввёл ноту → placeholder-пауза удаляется, остаток пуст | 🐞 баг 3, корень багов 2+3 |
| Полнотактовая пауза выбирается/редактируется | Verovio рисует `mRest`, а хит-тест ловит только `class="rest"` | 🐞 баг 2 |
| Ctrl+Shift+Del — full measure rest | `Measure.wholeRest()` создаётся автоматически; явной команды нет | ⚠️ |

## Итог: где экран расходится с MuseScore

### 🐞 Сломано (то, что видит Тимур) — чинить первым
1. **Выделение = кольцо, а не перекраска глифа** (§9, баг 1).
2. **Пауза на стане не выбирается** — `mRest` не в хит-тесте (§5, баг 2).
3. **При вводе ноты паузы пропадают** — не держится инвариант «такт полон паузами» (§5, баг 3).
   → Баги 2 и 3 — один корень: модель не хранит такт как всегда-полный реальными выбираемыми паузами.
4. **Диатоническая транспозиция игнорит тональность** (§3, всегда до-мажор).

### ❌ Отсутствует относительно MuseScore (не баги, а незакрытый паритет)
- Insert mode (вставка со сдвигом) — §12, заметное отличие рабочего процесса.
- Энгармоническая замена J — §3.
- Range-выделение (Shift+стрелки), выделение до границы такта, Ctrl+A — §9.
- Добавление ноты в аккорд по интервалу (Alt+1–9) — §4.
- Appoggiatura (длинный форшлаг) — §7.
- Q/W смена длительности «на лету», 3-я/4-я точки, длительности мельче 64th — §2.
- Flip лиги/бима, зеркало головки — §11.
- Input-by-duration / Rhythm / Real-time режимы — §12.
- Copy/paste диапазона (сейчас только одно событие) — §12.

### ✅ Уже соответствует MuseScore (не трогать)
Step-time ввод, липкая длительность, nearest-octave, Del→пауза, Re-pitch, 4 голоса с точными цветами, туплеты, tie/slur, acciaccatura, все 5 альтераций, транспозиция ±полутон/октава, Repeat, артикуляции, динамика/хайрпины, гравировка Verovio+Leland.
